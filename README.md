🌍 Wanderlust – Full Stack Travel Booking Application

Wanderlust is a fully functional full-stack web application designed to simulate a travel booking platform. Users can explore destinations, view listings, and book their dream vacations — all powered by modern web technologies.

🚀 Live Demo

Hosted on Render: https://new-wanderlust-cbyi.onrender.com

> Note: It may take a few seconds to load on the first visit due to Render’s free-tier cold start.


---

🛠️ Tech Stack

Frontend:

HTML, CSS, JavaScript

EJS Templating Engine

Bootstrap (for responsive UI)


Backend:

Node.js

Express.js

MongoDB (via Mongoose)

Cloudinary (for image uploads)


Other Tools:

Render (for deployment)

Dotenv (for managing environment variables)

Multer (for file uploads)

Method-Override (for RESTful routing)

---

🔑 Features

User authentication & authorization (if implemented)

Add, edit, and delete travel destinations

Upload multiple images per listing

View all bookings or individual packages

Clean and intuitive UI

RESTful API structure
